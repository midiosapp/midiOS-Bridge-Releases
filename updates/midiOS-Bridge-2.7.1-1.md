# midiOS Bridge 2.7.1 (1)

- Adds 1/16-note quantization for finalized MIDI clips directly from LiveGrid.
- Adds hold-to-Duplicate in LiveGrid, copying the playable clip directly above
  into the selected empty clip slot.
- Includes midiOS8x4 Remote Script build 30 with correlated clip-action results,
  guarded MIDI-clip quantization, and non-overwriting clip duplication.
- Preserves existing MIDI timing, connection, updater, and Ableton Integration
  behavior.
- Requires macOS 15.6 or later.
