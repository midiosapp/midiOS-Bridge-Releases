# midiOS Bridge 2.7.2 (1)

- Adds guided Marketplace creator onboarding from account setup through the
  existing creator tools.
- Refines the menu-bar experience with clearer live status and grouped access
  to connection, MIDI, library, Marketplace, and setup actions.
- Adds no new Bridge/iPhone protocol requirement and remains compatible with
  the current midiOS 2.7 release line.
- Keeps midiOS8x4 Remote Script build 30 unchanged and preserves existing MIDI
  timing, connection, updater, and Ableton Integration behavior.
- Requires macOS 15.6 or later.
