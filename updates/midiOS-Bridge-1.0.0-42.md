# midiOS Bridge 1.0.0 (42)

- Adds Bridge compatibility for midiOS 2.5.2 (2) and its unified Performance Control workflow.
- Keeps the selected Ableton device macros available to the new Ableton Macros performance mode.
- Retains valid CoreMIDI host timestamps for reliable MIDI delivery into Ableton Live.
- Shows each saved layout's Performance Control profile in the Layout Library inspector.
- Adds Marketplace package v2 capability inspection and minimum-build
  enforcement for Performance Control layouts while retaining package-v1
  compatibility.
- Requires macOS 15.6 or later.
