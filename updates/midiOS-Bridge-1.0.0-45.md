# midiOS Bridge 1.0.0 (45)

- Adds shared layout support for midiOS 2.6 Performance Modes with independent
  note and chord mappings.
- Previews Open Sky, Deep Focus, Voicing Bloom, directional spread, and Register
  Gravity assignments in transferred Total Recall layouts.
- Preserves safe inspection and migration behavior for older Performance
  Control layout schemas.
- Includes the connection, validation, Ableton integration, and Marketplace
  compatibility improvements prepared for midiOS 2.6.
- Requires macOS 15.6 or later.
